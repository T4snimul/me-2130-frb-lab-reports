\section{Objectives}
\begin{enumerate}
	\setlength{\itemsep}{0pt}
	      \setlength{\parskip}{0pt}
	      \setlength{\parsep}{0pt}
	\item To model the seven assigned parts in SolidWorks using parametric workflows.
	\item To produce fully defined 2D sketches and convert them into 3D geometry using features such as Extruded Boss/Base, Revolved Boss/Base, Cut, Fillet, Chamfer, and Shell.
	\item To apply feature organization: mates, feature order, mirrors, and patterns to create robust, modifiable parts.
	\item To document modeling decisions, common failure modes, and corrective steps for future design work.
	\item To compare modeling strategies and justify the choice of features for each part with reference to CAD best practices \cite{lab_01_solidworks_bible,lab_01_cad_fundamentals}.
\end{enumerate}
