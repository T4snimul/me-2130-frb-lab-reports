\section{Objectives}
\begin{enumerate}
  \setlength{\itemsep}{0pt}
        \setlength{\parskip}{0pt}
        \setlength{\parsep}{0pt}
  \item To become familiar with the user interface and basic functionalities of SolidWorks.
  \item To learn how to create and fully define 2D sketches using various sketching and dimensioning tools.
  \item To understand and apply fundamental 3D modeling features, specifically the Extruded Boss/Base and Revolved Boss/Base tools.
  \item To practice creating complete 3D solid parts from given 2D drawings by following a step-by-step modeling process.
\end{enumerate}
